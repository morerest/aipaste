# aipaste 底部卡片条 UI 改版设计

**日期：** 2026-07-24
**状态：** 已确认，待实现
**范围：** 历史面板、菜单栏入口及相关键盘交互

## 1. 目标

把当前居中的普通列表窗口改造成底部横向卡片条，使高频操作收敛为：

```text
⇧⌘V 或点击菜单栏图标 → 搜索/选择 → Enter 粘贴
```

本次同时解决三个问题：

1. 移除显式 `Paste` 按钮带来的重复操作感。
2. 提升文字和图片历史的视觉层级与浏览效率。
3. 提供清晰、稳定、适配深浅色的菜单栏图标，并让单击图标直接开关历史面板。

## 2. 非目标

- 不改变 SQLite 数据结构。
- 不增加 AI、云同步、收藏夹或文件剪贴板。
- 不增加复杂主题系统。
- 不改变默认全局快捷键 `⇧⌘V`。
- 不将应用改成 Dock 常驻应用；仍保持菜单栏 accessory 模式。

## 3. 视觉设计

### 3.1 面板

- 使用底部居中的浮动面板，宽度为当前屏幕可见宽度的约 80%，并设置合理的最小、最大宽度。
- 面板与屏幕左右、底部保持安全间距，避免贴边和遮挡 Dock。
- 高度约 300pt，采用 macOS 原生材质感、圆角和轻量阴影。
- 面板不在 Dock 中创建独立窗口项，继续浮于普通窗口上方。

### 3.2 顶部工具区

- 左侧显示 `aipaste` 和当前结果数量。
- 中部为搜索框，打开面板后可直接输入。
- 右侧为 `···` 菜单，包含“设置”“清空历史”和“退出 aipaste”。

### 3.3 卡片条

- 历史记录横向排列，可左右滚动。
- 文字卡片展示两到多行正文摘要、来源应用和相对时间。
- 图片卡片读取本地媒体数据并展示真实缩略图；加载失败时使用明确的图片占位符。
- 选中卡片使用高对比描边、背景变化和轻微缩放表达焦点。
- 卡片尺寸保持一致，长文本截断，不因内容长度改变整体布局。
- 无历史记录或搜索无结果时显示独立空状态。

## 4. 交互设计

- `⇧⌘V`：开关历史面板。
- 单击菜单栏图标：开关历史面板。
- 单击卡片：选中。
- 双击卡片或按 `Enter`：隐藏面板，将内容写入剪贴板并自动粘贴到先前应用。
- `←` / `→`：切换选中卡片，并确保选中卡片滚动到可见范围。
- `⌘C`：只复制选中项，不自动粘贴；在面板内短暂显示“已复制”。
- `Delete`：删除选中项并选择邻近卡片。
- `Esc`：关闭面板。
- 卡片右键菜单：提供“复制”和“删除”。
- 移除底部的 `Paste`、`Copy`、`Delete`、`Close` 按钮栏。

搜索框保持可编辑状态；当用户使用左右方向键、Enter、Delete 或 Command-C 时，这些快捷键由历史面板统一路由到卡片操作，普通文字输入仍进入搜索框。

## 5. 辅助功能权限降级

自动粘贴仍依赖 macOS 辅助功能权限。

- 权限存在：隐藏面板后向先前应用发送 `⌘V`。
- 权限不存在：内容仍复制到系统剪贴板，但不自动打开系统设置。
- 面板重新显示时提供非阻塞提示和“打开辅助功能设置”操作。
- 不使用模态 `NSAlert` 打断剪贴板工作流。

## 6. 菜单栏入口

- 使用 SF Symbol 风格的剪贴板模板图标，自动适配浅色和深色菜单栏。
- 不再使用可变宽度文字 `aipaste` 作为唯一入口，减少刘海屏或菜单拥挤时被隐藏的概率。
- 单击图标直接调用 `HistoryPanelController.toggle()`。
- 设置和退出入口移入历史面板右上角的 `···` 菜单。
- 保留 tool tip，便于用户识别应用名称和快捷键。

应用的 AppIcon 资源仍可在后续品牌化阶段补充；本次菜单栏图标不依赖 AppIcon。

## 7. 组件调整

### `MenuBarController`

- 从文字标题与 `NSMenu` 改为模板图标与直接 action。
- 持有状态项，避免生命周期结束导致入口消失。

### `HistoryPanelController`

- 根据当前屏幕可见区域计算底部面板尺寸和位置。
- 继续负责“先隐藏面板，再恢复前一应用焦点，然后粘贴”的时序。
- 移除辅助功能失败时的模态提示。

### `HistoryView`

- 改为顶部工具区、横向卡片条、空状态和非阻塞状态提示。
- 提供键盘事件和卡片双击入口。
- 提供设置、清空历史和退出回调。

### `HistoryViewModel`

- 提供前后选择、复制、删除、清空和图片缩略图读取接口。
- 对状态提示设置自动消失时间。
- 保持持久化访问经由 `SnippetStore`，视图不直接读取 SQLite。

## 8. 错误处理

- 图片媒体缺失或解码失败时展示占位符，不让整条历史面板崩溃。
- SQLite 查询、删除和清空失败时在面板内显示错误信息。
- 没有选中项时，粘贴、复制和删除快捷键不执行操作。
- 菜单栏 SF Symbol 不可用时回退到简短文字 `aipaste`，保证仍有入口。

## 9. 验证范围

### 自动化

- 现有哈希、存储、忽略规则和剪贴板摄取测试继续通过。
- 为选择移动、删除后的选择行为和清空历史补充 ViewModel 单元测试。
- 完整 Xcode build 与 test 成功。

### 手工视觉与交互

- 浅色、深色模式下菜单栏图标清晰可见。
- 点击菜单栏图标与 `⇧⌘V` 均能开关底部卡片条。
- 多显示器场景下，面板显示在当前主屏幕可见区域底部且不遮挡 Dock。
- 文字、图片、长文本和搜索无结果状态布局正确。
- Enter、双击、左右键、Command-C、Delete、Esc 均符合定义。
- 有、无辅助功能权限两条粘贴路径都不出现模态阻塞。
