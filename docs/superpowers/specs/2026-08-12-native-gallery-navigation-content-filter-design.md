# 原生画廊导航与内容类型筛选设计

**日期：** 2026-08-12  
**状态：** 已确认，待实现  
**范围：** 历史面板工具栏、横向卡片画廊、内容类型查询

## 1. 背景与目标

当前“回到最新”使用覆盖在卡片区右侧的圆形悬浮按钮。它会遮挡卡片，更接近移动端浮动按钮，而不是 macOS 工具栏控件。

本次改动有两个目标：

1. 使用 macOS 原生工具栏语义重做画廊滚动与“回到最新”入口；
2. 支持按“全部、文字、图片、图文”筛选卡片，并与搜索、来源应用和收藏筛选组合使用。

本文档取代 `2026-08-12-return-to-latest-card-design.md` 中的“卡片区右侧悬浮按钮”设计。上一版 ViewModel 的“选中最新并发出左对齐滚动请求”语义继续保留。

## 2. Apple 设计原则

方案遵循 Apple Human Interface Guidelines 的以下原则：

- 高频导航、搜索和筛选放在工具栏中，并按逻辑分组；
- 分段控件用于影响当前视图的紧密关联单选项；
- 使用标准 SF Symbol、帮助提示和系统交互状态；
- 滚动反馈使用系统滚动指示器，不在内容上方绘制自定义滚动控件；
- 控件布局保持稳定，不因暂无结果而突然消失或移动。

参考：

- Apple HIG — Toolbars: https://developer.apple.com/design/human-interface-guidelines/toolbars
- Apple HIG — Segmented controls: https://developer.apple.com/design/human-interface-guidelines/segmented-controls

## 3. 工具栏与滚动设计

### 3.1 回到最新

- 删除卡片区右侧的圆形悬浮按钮及其阴影、圆形材质背景和卡片区覆盖层。
- 将 `arrow.left.to.line` 作为统一筛选控件区的最左侧按钮，位于搜索输入框之前，并使用分隔线与搜索区域区分。
- 按钮采用现有工具栏高度和圆角体系，不单独绘制常驻圆形底板。
- 默认状态保持安静；悬停、按下和键盘聚焦时使用系统/主题已有的轻量反馈。
- 帮助提示和 VoiceOver 标签继续使用 `Back to Latest` / `回到最新`。
- 当前结果为空时按钮禁用但不隐藏，避免工具栏布局跳动。
- 即使第一张卡片已被选中，按钮仍保持可用，因为用户可能只滚动画廊而没有改变选择。
- 点击后选中当前结果的第一张卡片，并使用 `.leading` 锚点将它定位到画廊左侧。

### 3.2 横向滚动

- 卡片继续按从新到旧的顺序横向排列，最新卡片位于最左侧。
- 继续支持触控板、Magic Mouse 和鼠标滚轮的横向滚动。
- 将 SwiftUI 横向 `ScrollView` 的滚动指示器恢复为系统原生行为。
- 指示器何时出现由 macOS“显示滚动条”设置决定；应用不绘制自定义轨道、滑块或渐变遮罩。
- 方向键选择继续把目标卡片滚动到中间；“回到最新”使用左对齐，两种意图保持独立。

## 4. 内容类型筛选

### 4.1 筛选语义

新增四个互斥选项：

- `全部`：不限制 `SnippetKind`；
- `文字`：仅显示 `.text`；
- `图片`：仅显示 `.image`；
- `图文`：仅显示 `.mixed`。

内容类型筛选与以下条件取交集：

- 搜索文本；
- 来源应用；
- 仅收藏。

“清除全部筛选”将内容类型恢复为“全部”。内容类型不是“全部”时，`hasActiveFilters` 返回 `true`。

### 4.2 自适应控件

- 宽度充足时显示单选分段控件：`全部 / 文字 / 图片 / 图文`。
- 宽度不足时，使用 `ViewThatFits` 切换为单个内容类型菜单，菜单中用勾选状态显示当前选择。
- 两种呈现共享同一个 ViewModel 状态，不产生两套筛选逻辑。
- 分段控件使用文字标签，避免仅靠图标区分“图片”和“图文”造成歧义。
- 每个选项提供本地化文字和辅助功能标签。

## 5. 组件与数据流

### `SnippetKindFilter`

- 新增面向界面的筛选枚举：`.all`、`.text`、`.image`、`.mixed`。
- `.all` 映射为 `nil`，其余值映射到对应 `SnippetKind`。
- 枚举负责稳定标识与类型映射；本地化显示文字由 `WorkbenchStrings` 提供。

### `HistoryViewModel`

- 新增可发布的 `contentKindFilter`，默认 `.all`。
- 提供设置内容类型筛选的方法。
- `reload()` 将筛选映射为可选 `SnippetKind` 并传给 `SnippetStore.list`。
- `hasActiveFilters` 与 `clearAllFilters()` 纳入内容类型。
- 保留现有 `selectLatest()` 和专用滚动令牌。

### `SnippetStore`

- `list` 新增可选 `kind: SnippetKind?` 参数。
- 查询根据是否存在搜索词、来源应用和内容类型构造 `WHERE` 条件，并继续使用绑定参数，禁止拼接用户输入。
- 收藏排序和普通历史排序保持不变。
- 不修改数据库表结构或迁移版本。

### `HistoryView`

- 将“回到最新”移入统一筛选控件区并删除画廊覆盖层。
- 添加宽屏分段控件与窄屏菜单呈现。
- 将横向 `ScrollView` 改为显示系统滚动指示器。
- 保留键盘居中滚动与回到最新左对齐滚动监听。

### `WorkbenchStrings`

新增以下中英文文案：

- `All / 全部`
- `Text / 文字`
- `Images / 图片`
- `Mixed / 图文`
- `Content Type / 内容类型`

## 6. 状态、边界与错误处理

- 当前筛选无结果时展示既有“无匹配结果”空状态，工具栏仍保持可用，用户可以修改或清除筛选。
- 空结果时“回到最新”禁用；重新出现结果后自动恢复可用。
- 选中的卡片因筛选消失时，沿用现有 `reload()` 行为选择新结果的第一张卡片。
- 数据库查询失败时沿用现有非阻塞状态消息。
- 窄屏菜单与宽屏分段控件必须显示同一当前值。
- 不改变复制、粘贴、删除、收藏、缩略图加载或容量清理行为。

## 7. 验证范围

### 自动化测试

- `SnippetStore` 分别按 `.text`、`.image`、`.mixed` 返回准确结果；
- 内容类型与文本搜索、来源应用和收藏筛选正确取交集；
- ViewModel 默认使用“全部”，切换内容类型后重新加载对应卡片；
- `hasActiveFilters` 能识别内容类型筛选；
- `clearAllFilters()` 将内容类型恢复为“全部”；
- 现有“回到最新”选择、重复请求和空列表测试继续通过；
- 所有主题能够托管新的工具栏控件而不崩溃；
- 完整 XCTest 与 clean build 通过。

### 手工验证

- 卡片区不再出现圆形悬浮按钮，也不再遮挡最右侧卡片；
- 点击工具栏“回到最新”能选中第一张卡片并将其定位到左侧；
- 横向滚动使用系统原生滚动指示器，并遵循 macOS 系统设置；
- 宽屏显示四段筛选，窄屏自动收为菜单；
- 四种筛选状态和组合筛选结果正确；
- 六套皮肤、浅色/深色、降低透明度和增强对比度下控件清晰；
- VoiceOver 能识别“回到最新”、内容类型控件及四个选项；
- 中英文切换后文案正确，布局无明显截断。

## 8. 非目标

- 不支持一次同时选择多个内容类型；
- 不增加自定义滚动条、分页箭头或卡片边缘渐变；
- 不增加筛选结果计数徽标；
- 不改变剪贴板内容分类规则；
- 不改变数据表结构。
