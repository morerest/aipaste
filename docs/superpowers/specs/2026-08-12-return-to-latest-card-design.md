# 回到最新卡片设计

**日期：** 2026-08-12  
**状态：** 已确认，待实现  
**范围：** 历史卡片横向画廊

## 目标

为横向历史卡片画廊增加一个可见的一键入口。用户浏览到较旧记录后，点击该入口即可同时：

1. 选中当前结果中的第一张卡片；
2. 将第一张卡片滚动到画廊最左侧。

历史记录按更新时间从新到旧排列，因此第一张卡片就是当前搜索和筛选结果中的最新复制项。

## 交互与视觉

- 在卡片区右侧叠加一个悬浮图标按钮，不占用顶部搜索与筛选工具栏空间。
- 按钮使用 SF Symbol `arrow.left.to.line`。
- 中英文帮助文案和辅助功能标签分别为“回到最新”和“Back to Latest”。
- 画廊没有卡片时不显示按钮。
- 按钮始终可点击。即使第一张卡片已经被选中，用户也可能手动滚动到了旧卡片，因此点击仍需重新定位。
- 滚动使用简短动画，与现有方向键滚动反馈保持一致。

## 组件与数据流

### `HistoryViewModel`

- 新增“选择最新卡片”的动作。
- 动作在列表非空时把 `selectedID` 设置为 `snippets.first.id`。
- 动作递增专用的“回到最新”滚动令牌，让视图即使在选择未变化时也能收到定位请求。
- 空列表调用该动作时不改变选择，也不发出滚动请求。

专用令牌与现有方向键滚动令牌分开：方向键仍把卡片滚动到中间；回到最新动作则需要 `.leading` 锚点。这样视图无需根据选择变化猜测用户意图。

### `HistoryView`

- 使用叠层容器把悬浮按钮放在画廊右侧。
- 按钮触发 ViewModel 的“选择最新卡片”动作。
- 监听专用滚动令牌，读取当前 `selectedID`，调用 `ScrollViewProxy.scrollTo(id, anchor: .leading)`。
- 保留现有鼠标点击不自动居中、方向键选择后居中的行为。

### 本地化与文档

- 在 `WorkbenchStrings` 增加按钮的中英文帮助文案。
- 在 README 的历史画廊操作表中增加“回到最新”的说明。

## 边界与错误处理

- 空结果、搜索无结果和筛选无结果时不展示按钮。
- 若列表在请求发出前发生刷新，监听端找不到有效选择时直接忽略，不产生崩溃或错误提示。
- 本功能不改变数据库排序、剪贴板写入、粘贴流程或筛选逻辑。

## 验证

### 自动化测试

- 非空列表执行“回到最新”后，第一张卡片被选中。
- 即使第一张卡片原本已选中，每次执行仍递增专用滚动令牌。
- 空列表执行动作时不改变选择且不递增令牌。
- 完整 XCTest 套件和 macOS 构建通过。

### 手工验证

- 横向滚动到旧记录后，点击右侧按钮，最新卡片被选中并定位到最左侧。
- 第一张卡片已选中但画廊被手动滚走时，按钮仍可把画廊复位。
- 中英文界面下帮助提示和 VoiceOver 标签正确。
- 不同皮肤、浅色和深色模式下按钮清晰可见，且不遮挡卡片正文操作区。
