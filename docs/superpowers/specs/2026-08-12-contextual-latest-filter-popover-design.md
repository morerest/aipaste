# 上下文式“回到最新”与聚合筛选弹层设计

**日期：** 2026-08-12  
**状态：** 已完成交互与视觉确认，待用户复核文档  
**范围：** 历史面板工具栏、横向滚动位置反馈、筛选入口与筛选弹层

## 1. 背景

上一版把“回到最新”作为 `arrow.left.to.line` 图标放进搜索/筛选控件组，并把“全部、文字、图片、图文”四个内容类型平铺在工具栏。实际运行后出现两个产品问题：

1. “回到最新”是仅在用户滚离最新内容后才有意义的上下文动作，却长期占据工具栏第一视觉位；抽象图标也增加了理解成本。
2. 内容类型、收藏、来源应用与搜索被放在同一层级，四段内容筛选长期占用宽度，使工具栏显得拥挤，削弱了搜索这一首要任务。

本设计取代 `2026-08-12-native-gallery-navigation-content-filter-design.md` 中的工具栏呈现方案。现有内容类型查询、组合筛选和 `selectLatest()` 数据行为继续保留。

## 2. 产品目标

- 默认界面优先支持“搜索与浏览”，减少长期可见但当前无效的控件。
- 让“回到最新”只在用户确实需要时出现，并用可读文字替代难懂的滚动图标。
- 把内容类型、收藏和来源应用组织为一个结构化筛选入口，保持组合筛选能力。
- 保证工具栏中心区域稳定；上下文按钮出现或消失时，搜索框不能移动。
- 保留原生 macOS 的操作方式、主题适配、键盘与辅助功能支持。

## 3. 信息架构

工具栏分为三个互不争夺布局的区域：

- **左侧品牌区：** 应用图标、AI paste 品牌，以及按需出现的浅蓝“回到最新”导航胶囊。
- **中心任务区：** 搜索框和“筛选”按钮，始终保持在面板水平中心。
- **右侧全局区：** 现有溢出菜单。

中心任务区使用既有居中容器，不依靠左右两侧等宽。左侧“回到最新”的出现和隐藏不得推动搜索框或筛选按钮。

默认状态只显示品牌、搜索、筛选和溢出菜单。收藏、内容类型和来源应用不再作为独立工具栏控件常驻。

## 4. “回到最新”设计

### 4.1 呈现

- 删除工具栏中的方框式 `arrow.left.to.line` 图标按钮。
- 改为浅蓝导航胶囊：`arrow.left` SF Symbol 配合本地化的“回到最新”文字；不再使用排版字符 `‹`。
- 按钮位于左侧品牌之后，与品牌保持 8pt 间距。
- 按钮高度 26pt、连续圆角 7pt，图标与文字间距 5pt，水平内边距 9pt。
- System Glass 默认使用系统强调蓝文字、低透明度浅蓝底和细蓝色边框；悬停时底色加深，按下时轻微降低亮度，不使用缩放动画。
- 其他五套固定皮肤使用各自 `themeStyle.accent` 派生前景、背景和边框，保持同一层级并满足增强对比度模式。
- 按钮出现时采用 160ms 淡入和 4pt 水平位移动画；隐藏使用 160ms 淡出，不使用弹簧动画。
- VoiceOver 继续只读出 `Back to Latest` / `回到最新`，不单独朗读箭头。

### 4.2 出现条件

- 当前筛选结果非空，并且 macOS 原生画廊的横向滚动偏移超过 **70pt（卡片宽度的 1/3）** 时显示。
- 阈值用于过滤轻微触控板位移，避免按钮频繁闪烁。
- 位于最新位置、结果为空或滚回阈值以内时隐藏。
- 条件基于原生 `NSClipView` 的实际横向偏移，不基于当前选中卡片，也不维护一份持久化的业务状态。

### 4.3 行为

- 点击后继续调用现有 `HistoryViewModel.selectLatest()`：选择当前结果第一张卡片，并发出专用滚动请求。
- 画廊使用 `.leading` 锚点把第一张卡片定位到左侧。
- 原生横向偏移回到阈值以内后，按钮自然隐藏。
- 键盘左右选择仍把目标卡片滚动到中间；两种滚动意图保持独立。
- VoiceOver 标签和帮助提示使用 `Back to Latest` / `回到最新`。

## 5. 中心搜索与筛选入口

### 5.1 搜索框

- 搜索仍是中心区域的主要控件，继续支持现有内容、来源应用和收藏备注搜索。
- 结果数量继续显示在搜索框尾部。
- 搜索词继续通过搜索框内的独立清除按钮清空。
- 搜索词不计入筛选徽标数量。

### 5.2 筛选按钮

- 搜索框右侧放置一个带文字的“筛选”按钮，使用标准筛选符号 `line.3.horizontal.decrease`。
- 没有启用筛选时，按钮保持中性样式且不显示徽标。
- 启用筛选后，按钮使用当前主题的选中状态，并显示蓝色数量徽标，例如“筛选 2”。
- 点击按钮打开或关闭筛选 Popover。
- 辅助功能标签使用 `Filters` / `筛选`，激活筛选时读出启用数量。

## 6. 筛选 Popover

### 6.1 容器

- 使用 SwiftUI/macOS 原生 Popover，宽度 280pt。
- Popover 锚定在“筛选”按钮下方，不遮挡搜索输入区域。
- 切换筛选条件时 Popover 保持打开，便于连续组合多个条件。
- 点击 Popover 外部、再次点击筛选按钮或关闭历史面板时关闭。
- 空结果时仍可打开和操作 Popover。

### 6.2 内容类型

第一组标题为“内容类型”，以纵向单选列表呈现：

- 全部
- 文字
- 图片
- 图文

同一时间只能选中一项，当前项显示系统勾选/单选状态。默认“全部”不构成激活筛选。

### 6.3 收藏

第二组标题为“收藏”，包含“仅显示收藏”开关。开启时构成一个激活筛选维度。

### 6.4 来源应用

第三组标题为“来源应用”，首行显示当前选择；默认显示“全部应用”。点击后使用菜单展开现有来源应用列表。非“全部应用”时构成一个激活筛选维度。

来源应用菜单关闭后，父级筛选 Popover 保持打开。

### 6.5 清除筛选

- 只要内容类型、收藏或来源应用中至少一项处于非默认状态，Popover 底部显示“清除筛选”。
- 点击后把内容类型恢复为“全部”、关闭“仅显示收藏”、来源应用恢复为“全部应用”。
- **不清空搜索词**；搜索由搜索框自身管理。
- 清除后 Popover 保持打开，用户可立即重新设置条件。

## 7. 筛选计数与数据状态

`HistoryViewModel` 增加只读的 `activeFilterCount`：

- 内容类型不是“全部”：`+1`
- 仅收藏开启：`+1`
- 来源应用不是“全部应用”：`+1`
- 搜索词：不计数

计数范围是“激活的筛选维度”，不是已匹配的卡片数量，也不是选项数量。

现有 `hasActiveFilters` 继续包含搜索词，用于空结果文案和工具栏状态。新增 `clearStructuredFilters()`，只清除三类结构化筛选；现有 `clearAllFilters()` 保留给需要同时清除搜索的内部/未来入口，但 Popover 不调用它。

## 8. 组件边界

### `HistoryView`

- 负责三段式工具栏布局、Popover 开关、横向画廊和滚动位置反馈。
- 读取 macOS 原生 `NSClipView` 的横向 bounds 偏移，计算是否显示上下文按钮。
- 保留现有键盘居中滚动与回到最新左对齐滚动监听。
- 删除常驻内容类型分段控件、独立收藏按钮和独立来源应用菜单。

### `HistoryFilterPopover`

- 新增独立 SwiftUI 组件，负责内容类型、收藏、来源应用和清除筛选的视觉与交互。
- 使用同一个 `HistoryViewModel` 筛选状态，不复制查询逻辑。
- 接收本地化与主题上下文，支持六套皮肤、浅色/深色、降低透明度和增强对比度。

### `GalleryScrollOffsetObserver`

- 新增轻量 AppKit/SwiftUI 桥接组件，监听原生 `NSClipView.boundsDidChangeNotification`。
- 直接上报横向滚动偏移，避免 macOS 实时滚动期间 SwiftUI Geometry Preference 不刷新的问题。
- 视图按偏移超过 70pt（210pt 卡片宽度的 1/3）计算“已滚离最新”。
- 该反馈只用于界面呈现，不进入数据库或 ViewModel 持久状态。

### `HistoryViewModel`

- 保留现有 `contentKindFilter`、`favoritesOnly`、`sourceAppFilter` 和查询组合逻辑。
- 新增 `activeFilterCount` 与只清除结构化筛选的方法。
- 保留 `selectLatest()` 及专用滚动令牌。

### `SnippetStore`

- 不改数据库结构和查询语义。
- 继续对内容类型、来源应用、收藏和搜索条件取交集。

## 9. 状态与边界

- 历史为空：不显示“回到最新”；筛选按钮仍可用，以便清除导致空结果的条件。
- 筛选后第一张结果变化：新的第一张卡片成为“最新结果”；列表重新加载后重新计算位置。
- Popover 打开期间列表变化：保留当前筛选状态，结果数量实时更新。
- 当前来源应用从历史中消失：沿用 ViewModel 现有逻辑恢复“全部应用”，徽标计数同步减少。
- 用户只滚动但不改变选择：“回到最新”仍出现并可用。
- 第一张卡片已选中但画廊已滚远：点击仍发出新的滚动请求。
- 减少动态效果开启时，取消位移动画，仅使用短淡入淡出或无动画状态切换。
- 画廊继续使用 macOS 原生横向滚动指示器，并遵循系统“显示滚动条”偏好；不增加自定义滚动条或分页箭头。

## 10. 本地化与辅助功能

新增或调整中英文文案：

- `Filters / 筛选`
- `Content Type / 内容类型`
- `Favorites / 收藏`
- `Favorites Only / 仅显示收藏`
- `Source App / 来源应用`
- `Clear Filters / 清除筛选`
- `Back to Latest / 回到最新`

要求：

- VoiceOver 能读出“回到最新”、筛选按钮、激活筛选数量、三组标题及所有选项。
- 内容类型不能只靠图标区分。
- 收藏使用系统 Toggle 语义，来源应用使用系统 Menu 语义。
- 键盘可聚焦筛选按钮、Popover 内所有选项和清除筛选操作。

## 11. 验证范围

### 自动化测试

- `activeFilterCount` 对内容类型、收藏和来源应用分别计数，并正确组合为 0–3。
- 搜索词不会增加 `activeFilterCount`，但仍使 `hasActiveFilters` 为真。
- 清除结构化筛选会重置内容类型、收藏和来源应用，同时保留搜索词。
- 现有内容类型与搜索、应用、收藏组合查询测试继续通过。
- 回到最新的滚动偏移阈值计算覆盖：70pt 阈值内隐藏、超过 70pt 显示、空结果隐藏。
- `selectLatest()` 的选择、重复请求和空列表测试继续通过。
- 六套主题均能托管主工具栏与 `HistoryFilterPopover`。
- 完整 XCTest 与 clean build 通过。

### 手工验证

- 默认状态没有难懂的方框滚动图标，也不平铺四种内容类型。
- 搜索框始终居中，“回到最新”出现或消失时不发生位移。
- 轻微触控板移动不触发按钮；滚离超过 70pt 后平滑出现。
- 点击“回到最新”后第一张结果左对齐，按钮随位置恢复而隐藏。
- Popover 可连续设置内容类型、收藏和来源应用，不因单次选择关闭。
- 徽标准确显示 0–3 个激活维度，搜索词不影响徽标。
- “清除筛选”保留搜索词，并能从空结果状态恢复。
- 中英文、六套皮肤、浅色/深色、降低透明度、增强对比度和减少动态效果下布局与状态清晰。

## 12. 非目标

- 不支持一次选择多个内容类型。
- 不把搜索词纳入筛选徽标。
- 不显示各内容类型的数量。
- 不增加自定义滚动条、卡片分页箭头或边缘渐变。
- 不改变剪贴板内容分类、数据库结构、复制、粘贴、删除、收藏或缩略图逻辑。
