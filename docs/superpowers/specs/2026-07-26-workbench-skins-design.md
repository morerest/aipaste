# aipaste 工作台皮肤系统设计

**日期：** 2026-07-26
**状态：** 视觉方案已确认，待实现
**范围：** 剪贴板历史工作台与设置中的皮肤选择器

## 1. 目标

在不改变现有布局和交互的前提下，为剪贴板工作台增加皮肤功能：

- 当前界面保留为“默认”皮肤。
- 新增暖纸、苔庭、石墨、雾蓝、樱灰 5 套皮肤，共 6 套。
- 皮肤选择持久化，重新启动应用后保持不变。
- 选择后立即影响当前或下一次打开的历史工作台，无需重启应用。
- 每套皮肤具有明确辨识度，同时保持文字、图片、来源和选中状态清晰可读。

## 2. 设计边界

皮肤允许改变：

- 工作台背景颜色、材质、渐变、边缘高光和阴影。
- 搜索与筛选控件的背景、描边、焦点颜色和圆角。
- 卡片背景、描边、圆角、阴影、分隔线和选中效果。
- 品牌强调色、文字明度、字重和字距。
- 石墨皮肤中的代码内容及元信息可以使用等宽字体。

皮肤不改变：

- 工作台尺寸、工具栏位置、卡片尺寸和横向排列方式。
- 搜索、收藏、来源筛选、菜单和快捷键行为。
- 卡片正文的信息结构、图片缩略图策略和来源应用图标。
- 设置窗口、菜单栏图标、应用图标和系统确认对话框。
- 剪贴板数据、数据库结构和粘贴流程。

正文默认继续使用系统字体。皮肤只能调整有限的字重、字距和元信息字体，避免为装饰牺牲可读性。

## 3. 最终皮肤集合

### 3.1 默认 · System Glass

保留当前实现，不进行视觉调整。

- 使用 macOS 原生玻璃与系统动态颜色。
- 蓝紫渐变用于品牌和搜索焦点。
- 面板圆角 24pt，卡片圆角 16pt。
- 自动跟随 macOS 浅色和深色外观。

### 3.2 暖纸 · Warm Paper

温暖、安静、有阅读感。

- 面板：奶油米色渐变，约 `#EFE8DA → #E8DFCE`。
- 卡片：暖白纸张色，约 `#FFFAF0`。
- 正文：深暖灰，约 `#3D352B`。
- 强调色：陶土棕，约 `#BD6642`。
- 面板圆角 17pt，卡片圆角 10pt。
- 弱化玻璃感，使用细微纸张层次和柔和短阴影。

### 3.3 苔庭 · Moss Garden

自然、低饱和，适合长时间使用。

- 面板：灰绿色渐变，约 `#DCE4D7 → #CBD7CA`。
- 卡片：带少量透明度的暖灰白。
- 正文：墨绿色灰，约 `#26352C`。
- 强调色：苔绿色，约 `#3E7655`。
- 面板圆角 26pt，卡片圆角 18pt。
- 使用柔和漫射高光，选中卡片略微提亮。

### 3.4 石墨 · Graphite

克制、专业、偏开发者工具气质。

- 面板：深石墨渐变，约 `#1A1B1D → #25272A`。
- 卡片：约 `#2C2E31`。
- 正文：浅灰白，约 `#F2F3F3`。
- 强调色：薄荷绿，约 `#67DCA3`。
- 面板圆角 14pt，卡片圆角 7pt。
- 减少阴影与发光；选中状态仅使用薄荷绿细边与轻微底色变化，不增加左侧内嵌标记。
- 代码内容及卡片元信息使用系统等宽字体。

### 3.5 雾蓝 · Mist Blue

冷静、清爽、有空气感，但避免霓虹科技风。

- 面板：浅蓝灰雾面，约 `#DCE6EB`，辅以低对比冷色渐变。
- 卡片：半透明冷白，约 `rgba(250,253,254,0.88)`。
- 正文：深蓝灰，约 `#24343E`。
- 强调色：雾蓝，约 `#4D819B`。
- 面板圆角 23pt，卡片圆角 15pt。
- 使用轻量玻璃模糊和克制的蓝色焦点环。

### 3.6 樱灰 · Rose Ash

柔和、精致、中性，不采用甜美或高饱和粉色。

- 面板：灰粉渐变，约 `#E5DADD → #D8C9CD`。
- 卡片：暖灰白，约 `#FCF8F7`。
- 正文：深莓灰，约 `#3D3135`。
- 强调色：暗莓红，约 `#9A6170`。
- 面板圆角 19pt，卡片圆角 11pt。
- 选中状态仅使用低对比莓红描边与轻微底色变化，避免左侧粗线和粉色光晕。

## 4. 外观与辅助功能规则

- 默认皮肤继续跟随 macOS 浅色或深色外观。
- 5 套自定义皮肤保持固定视觉身份；切换系统外观不会把暖纸等皮肤自动转换成另一套配色。
- 所有皮肤的选中卡片均使用完整描边与轻微底色变化；不使用左侧竖条，避免与外框叠加成视觉瑕疵。
- 自定义皮肤只覆盖历史工作台面板，不改变应用其他窗口的系统外观。
- 开启“降低透明度”时，材质背景回退为对应皮肤的实色或近似不透明色。
- 开启“增强对比度”时，提高文字、卡片边框、焦点环和分隔线的对比度。
- 破坏性操作继续使用系统红色，收藏继续使用系统橙色；皮肤强调色主要用于选择、搜索焦点和品牌点缀。

## 5. 主题模型

新增稳定、可持久化的皮肤枚举：

```swift
enum WorkbenchTheme: String, CaseIterable, Identifiable, Codable {
    case systemGlass
    case warmPaper
    case mossGarden
    case graphite
    case mistBlue
    case roseAsh
}
```

原始值作为 `UserDefaults` 存储值，发布后保持稳定。显示名称由本地化层提供，不使用显示文案作为持久化标识。

每个枚举值映射到一个只读 `WorkbenchThemeStyle`。该样式集中提供：

- 面板、控件、卡片和文字的语义颜色。
- 面板、控件、卡片和图片的圆角。
- 边框宽度与透明度。
- 普通和选中状态的阴影参数。
- 搜索焦点、选择状态和品牌强调样式。
- 材质类型、背景遮罩和可选渐变。
- 元信息是否采用等宽字体。

视图只读取语义属性，例如 `theme.cardBackground`、`theme.selectionStroke`，不再直接散落具体色值。功能状态色仍由单独的系统语义色提供。

## 6. 数据与更新流程

1. `AppPreferences` 从 `UserDefaults` 读取皮肤原始值。
2. 未保存过皮肤时使用 `.systemGlass`。
3. 遇到未知或已失效的原始值时安全回退到 `.systemGlass`。
4. `PreferencesViewModel` 暴露当前皮肤，并在用户选择时立即写入偏好。
5. `AppState` 将同一份偏好对象传给 `HistoryPanelController`。
6. 历史面板显示或设置发生变化时读取最新皮肤，更新 `HistoryView`。

不引入数据库表，不迁移剪贴板数据，也不需要网络或资源下载。

## 7. 设置界面

在设置窗口顶部新增“外观 / Appearance”区块：

- 使用 2 列 × 3 行的皮肤预览卡片。
- 每张预览展示面板色、卡片色、强调色和选中状态的简化缩略图。
- 预览下方显示本地化名称。
- 当前选择使用系统勾选标记和清晰描边。
- 点击立即保存并更新历史工作台，不提供额外“应用”按钮。
- 键盘用户可以 Tab 聚焦并通过 Space 或 Enter 选择。
- VoiceOver 读出皮肤名称及是否已选中。

设置窗口自身继续使用系统样式，避免换肤造成设置项可读性或一致性问题。

## 8. 组件边界

### `WorkbenchTheme`

定义稳定 ID、显示顺序和本地化键，不包含业务逻辑。

### `WorkbenchThemeStyle`

集中管理全部视觉令牌。它不读取 `UserDefaults`，也不操作视图状态。

### `WorkbenchThemePreview`

设置页使用的小型静态预览。只消费主题样式，不依赖剪贴板记录或数据库。

### `AppPreferences` / `PreferencesViewModel`

负责读取、保存和公开用户选择。

### `HistoryPanelController` / `HistoryView`

控制器负责把当前皮肤传给工作台；工作台和卡片通过统一主题样式渲染，不自行读取偏好。

## 9. 错误与兼容处理

- 未知皮肤 ID、偏好损坏或读取失败时回退到默认皮肤。
- 主题定义不依赖外部图片和字体，因此不存在资源下载失败路径。
- 如果某种 macOS 材质不可用，使用该主题的实色背景作为回退。
- 皮肤切换不得中断搜索焦点、当前筛选、选中卡片或键盘操作。
- 已显示的状态提示、权限提示和菜单在切换皮肤后仍保持当前状态。

## 10. 验证范围

### 自动化测试

- 6 个 `WorkbenchTheme` 原始值可稳定编码和解码。
- 没有保存值时返回默认皮肤。
- 未知保存值回退到默认皮肤。
- 皮肤选择可通过 `AppPreferences` 持久化并重新读取。
- `PreferencesViewModel` 更换皮肤时触发保存和面板更新回调。
- 6 套主题均提供完整样式，不出现缺失颜色或非法尺寸。
- 设置页可承载全部 6 张预览卡片。

### 手工视觉与交互验证

- 分别检查 6 套皮肤的文字、图片、混合内容、收藏和选中状态。
- 检查长文本、中文、英文、URL 和代码片段的可读性。
- 验证搜索聚焦、来源筛选、收藏筛选和状态提示。
- 验证切换皮肤后搜索内容、筛选条件和选中项不丢失。
- 验证默认皮肤在 macOS 浅色和深色模式下保持现状。
- 验证 5 套自定义皮肤在系统外观切换后保持各自身份。
- 验证“降低透明度”和“增强对比度”。
- 验证 VoiceOver 名称、键盘选择以及不同显示器上的展示效果。

## 11. 非目标

- 不允许用户自定义色值或创建皮肤。
- 不支持从网络下载、导入或导出皮肤。
- 不按时间、壁纸或当前应用自动切换皮肤。
- 不为每套皮肤单独设计工具栏布局或卡片尺寸。
- 不改变应用图标、菜单栏图标和设置窗口外观。
- 本阶段不增加皮肤商店、付费解锁或云同步。
